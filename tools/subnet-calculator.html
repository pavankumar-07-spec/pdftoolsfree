What is IPv4 Subnetting?

Subnetting is the practice of dividing a single large physical network into smaller, logical sub-networks (subnets). It improves network security, reduces broadcast traffic congestion, and optimizes IP address allocation across organizations.

Subnetting Formulas

  • Total Addresses: $N_{total} = 2^{(32 - \text{CIDR})}$
  • Usable Hosts: $N_{usable} = 2^{(32 - \text{CIDR})} - 2$   (subtract 2 for Network & Broadcast IDs)
  • Network ID: $\text{IP} \land \text{Subnet Mask}$ (Bitwise AND)
  • Broadcast ID: $\text{Network ID} \lor \text{Wildcard Mask}$ (Bitwise OR)

Solved Worked Example

Example Problem:

Find the Network ID, Broadcast ID, and Usable Host Range for IP address $192.168.1.50/26$.

Step 1: Subnet Mask for /26: 26 ones $\to$ 255.255.255.192

Step 2: Total & Usable Hosts: $2^{32-26} = 64$ total addresses, $64 - 2 = 62$ usable hosts.

Step 3: Network ID: $192.168.1.50 \land 255.255.255.192 = 192.168.1.0$

Step 4: Broadcast ID: $192.168.1.0 \lor 0.0.0.63 = 192.168.1.63$
