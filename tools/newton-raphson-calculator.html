What is the Newton-Raphson Method?

The Newton-Raphson Method (also known simply as Newton's Method) is an extremely fast numerical root-finding algorithm. Starting from an initial guess $x_0$, it constructs tangent lines to the curve $y = f(x)$ to rapidly converge towards the root where $f(x) = 0$.

Mathematical Formula

Each successive approximation $x_{n+1}$ is computed using the derivative $f'(x_n)$:

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

Solved Worked Example

Example Problem:

Find the root of $f(x) = x^3 - x - 2 = 0$ near $x_0 = 1.5$ with tolerance $\epsilon = 0.0001$.

Derivative: $f'(x) = 3x^2 - 1$

Iteration 1 ($n=0$):
$f(1.5) = 1.5^3 - 1.5 - 2 = -0.125$
$f'(1.5) = 3(1.5)^2 - 1 = 5.75$
$x_1 = 1.5 - \left(\frac{-0.125}{5.75}\right) \approx 1.521739$

Iteration 2 ($n=1$):
$x_2 = 1.521739 - \left(\frac{0.001898}{5.9499}\right) \approx 1.521380$   (Converged!)
